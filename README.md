# GeoMetric Beta

Мессенджер в стиле Telegram. **Сервер написан на Python** (aiohttp + python-socketio + WebRTC-сигналинг) и **сам же отдаёт сайт** (`public/`) — один сервис на Render, без сборки фронтенда.

## Что есть
- Вход и регистрация **только по e-mail**: код из 5 цифр приходит на почту.
- **Вход по QR-коду**: на компьютере показывается QR → на телефоне (уже в аккаунте) *Настройки → Устройства → Подключить устройство* → подтверждение → компьютер входит. Работает через Socket.IO, QR живёт 60 с и обновляется.
- Личные чаты, группы, каналы, «Избранное», бот `GeoMetric`.
- Текст с форматированием, ответы, пересылка, редактирование, удаление (у себя / у всех), закрепы, черновики, отложенная отправка, «без звука».
- Реакции (двойной клик — быстрая), опросы и викторины, стикеры, геопозиция, файлы, фото/видео с подписями.
- **Голосовые** и **видео-кружки** (удерживайте кнопку справа; клик по значку — смена режима).
- **Аудио/видеозвонки** 1-на-1 (WebRTC), демонстрация экрана, микрофон/камера.
- Профиль: аватар с кроппером, имя, @username, «О себе», дата рождения (с приватностью), цвет профиля, эмодзи-статус.
- Настройки: тема (авто/светлая/тёмная/ночная), акцент, обои, размер текста, скругление, звуки, уведомления, приватность, чёрный список, устройства/сеансы, язык RU/EN.
- Синхронизация настроек между устройствами, глобальный поиск, контакты, список звонков, медиа/файлы/голос/ссылки в информации о чате.

## Новое в этой версии
- **GeoAI** ✓ — ИИ-помощник (чат «GeoAI», помнит контекст, `/clear` сбрасывает его). Нужен ключ: задайте `AI_API_KEY` (+ `AI_BASE_URL`, `AI_MODEL`). Бесплатные варианты: Groq (`https://api.groq.com/openai/v1`, `llama-3.3-70b-versatile`), Google Gemini (`https://generativelanguage.googleapis.com/v1beta/openai`, `gemini-2.0-flash`), OpenRouter (`https://openrouter.ai/api/v1`, модели `…:free`). Без ключа GeoAI честно сообщает, что не настроен.
- **QR и ссылки профиля**: *Настройки → QR* — QR с логотипом, ссылка `https://ваш-сайт/u/username` (открывает чат/профиль), скачивание PNG, сканер QR камерой.
- **Галочки**: пользователь ✓, группы/каналы — `[VER]` перед названием. **[GEO]** — модераторы: баны, «кик» из аккаунта, получают жалобы.
- **BotFather**: `/newbot`, `/mybots`, токен, имя, описание, аватар, команды, приветствие, ответ по умолчанию, webhook, удаление. Боты работают через Bot API: `/bot<token>/getMe|getUpdates|sendMessage|setWebhook…` и inline-кнопки.
- **Звук и видео**: выбор микрофона, камеры, динамиков, проверка уровня и превью.
- **Пароль**: *Настройки → Конфиденциальность → Пароль* — дополнительный способ входа (e-mail+код остаётся).
- **Жалобы**: «Пожаловаться» в профиле/чате → GEO-модераторам и в консоль.

## Консоль владельца
**Самый простой способ — прямо в окне Python (cmd/терминал), где запущен `python app.py`.** Когда сервер запущен у вас на компьютере, в этом же окне появится строка «Консоль владельца активна» — просто печатайте команды и жмите Enter:
```
verify @ваш_ник      # выдать себе галочку ✓
geo @ваш_ник         # выдать себе [GEO]
verify-chat @канал   # [VER] каналу
stats / users / help / export
```
Сначала зарегистрируйтесь в приложении и задайте себе @username — потом выдавайте. Права «владельца» для этого не нужны: консоль окна доверяет тому, кто запустил сервер.
На Render терминала нет — там откройте **`https://ваш-сайт/admin`**, введите `ADMIN_KEY` (Render → Environment) и пользуйтесь той же консолью в браузере.
Остальные способы:
Владельцы — e-mail из `OWNER_EMAILS`. Открывается в приложении (*Настройки → Консоль владельца*, сессия владельца, либо ввод `ADMIN_KEY`), а также из терминала:
```bash
python manage.py help
python manage.py verify @username        # галочка ✓
python manage.py geo @username           # статус [GEO]
python manage.py verify-chat @channel    # [VER]
python manage.py export backup.zip       # ZIP со всеми пользователями и чатами
```
Команды: `help stats users whois verify unverify geo ungeo owner unowner verify-chat unverify-chat ban unban kick resetpass bots delbot reports resolve announce export ai`.
Для GEO-модераторов в чате с GeoMetric: `/ban @u`, `/unban @u`.

## Сохранение и перенос пользователей (ZIP)
Все данные лежат в Postgres (или `DATA_DIR/db.json`). В консоли владельца — **«Скачать ZIP»** (или `python manage.py export`), и **«Импорт ZIP»** на новой установке/после обновления — всё восстановится (аккаунты, чаты, боты, галочки, медиа). Импорт ЗАМЕНЯЕТ текущие данные. Делайте бэкап перед каждым обновлением.

## Запуск локально
```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py            # http://localhost:3000
```
Пока почта не настроена, сервер работает в **демо-режиме**: 5-значный код показывается на экране и в логах.

## Деплой на Render
1. Залейте папку в GitHub.
2. Render → **New → Blueprint** → выберите репозиторий (используется `render.yaml`: веб-сервис + бесплатный Postgres).
   Либо вручную: *Web Service*, Runtime **Python 3**, Build `pip install -r requirements.txt`, Start `python app.py`, переменная `DATABASE_URL` из Render Postgres.
3. **Почта** (обязательно для настоящей регистрации). На бесплатном Render исходящий SMTP заблокирован, поэтому используйте HTTPS-API:
   - Brevo: `BREVO_API_KEY` + `MAIL_FROM` (подтверждённый отправитель), или
   - Resend: `RESEND_API_KEY` + `MAIL_FROM`.
   - (SMTP: `SMTP_HOST/PORT/USER/PASS` — только на платных тарифах.)
   После этого поставьте `HIDE_DEV_CODE=1`.
4. Откройте выданный адрес `https://…onrender.com` — HTTPS нужен для камеры, микрофона и звонков.

### Важно
- **Без `DATABASE_URL` (или платного Render Disk с `DATA_DIR`) данные пропадут** при перезапуске: диск бесплатного Render эфемерный. Медиа тоже хранятся в Postgres (до 60 МБ на файл).
- Бесплатный сервис Render «засыпает» без трафика — первое открытие может занять около минуты.
- Звонки идут напрямую (WebRTC) через публичные STUN. За строгими NAT/мобильными сетями нужен TURN: задайте `TURN_URL`, `TURN_USER`, `TURN_PASS`.
- Бот Telegram-уровня (Bot API) реализован частично: основные методы и inline-кнопки, не весь API. Групповых звонков нет — только 1-на-1.
- Сквозного шифрования (секретных чатов) нет: сообщения хранятся на сервере.

## Структура
- `app.py` — весь бэкенд: REST API, Socket.IO, QR-вход, звонки, почта, хранилище, раздача сайта.
- `public/` — фронтенд (HTML/CSS/JS), отдаётся этим же сервером.
- `requirements.txt`, `render.yaml`, `.python-version` — для деплоя.
- `scripts/build-icons.js` — (необязательно) пересборка набора иконок, нужен Node и `npm i lucide-static`.
