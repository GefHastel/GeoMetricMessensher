GeoMetric

Мессенджер со сквозным шифрованием. Введите адрес вашего сервера — приложение запомнит его.

Адрес выдаёт тот, кто поднял сервер GeoMetric (ваш компьютер, VPS или туннель). Для шифрования и звонков нужен https:// — по http приложение работает без шифрования.
