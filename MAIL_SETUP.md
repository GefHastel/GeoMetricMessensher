# Как настроить почту для входа (код из 5 цифр)

Бесплатный Render **блокирует SMTP** (порты 25/465/587), поэтому используем почтовый сервис по HTTPS-API. Выберите один.

## Вариант A — Brevo (бесплатно ~300 писем/день, не нужен свой домен)
1. Зарегистрируйтесь на https://brevo.com.
2. *Senders, Domains & Dedicated IPs → Senders → Add a sender*: укажите свой e-mail (например Gmail), подтвердите письмом.
3. *SMTP & API → API Keys → Generate a new API key* — скопируйте ключ (`xkeysib-…`).
4. В Render → ваш сервис → **Environment** добавьте:
   - `BREVO_API_KEY` = ключ
   - `MAIL_FROM` = `GeoMetric <ваш-подтверждённый@email>` (именно подтверждённый отправитель!)
   - `HIDE_DEV_CODE` = `1`
5. Сохраните — сервис перезапустится. Попробуйте зарегистрироваться; если письмо не приходит, проверьте «Спам» и *Brevo → Transactional → Logs*.

## Вариант B — Resend (бесплатно 100 писем/день)
1. https://resend.com → *API Keys → Create*.
2. Без своего домена можно слать только с `onboarding@resend.dev` и **только на ваш собственный e-mail** (для теста). Для всех пользователей нужен домен: *Domains → Add Domain* и добавьте DNS-записи (SPF/DKIM) у регистратора.
3. Render → Environment: `RESEND_API_KEY`, `MAIL_FROM` = `GeoMetric <no-reply@ваш-домен>`, `HIDE_DEV_CODE=1`.

## Проверка
- Пока ни один ключ не задан, сервер в **демо-режиме**: код показывается на экране входа (не оставляйте так в проде).
- В логах Render при отправке пишется результат; ошибки API (неподтверждённый отправитель, неверный ключ) видны там же.

## Советы
- Gmail как отправитель в Brevo работает, но письма могут попадать в спам; домен с SPF/DKIM — надёжнее.
- Ваш e-mail владельца — в `OWNER_EMAILS`, войдите им и откроется «Консоль владельца».
